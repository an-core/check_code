## Возможности
- **Проверка синтаксиса** - быстрый разбор кода с подсветкой строк, в которых найдены ошибки
- **Автоопределение языка** - приложение само угадывает, на каком языке написан код
- **Форматирование** - приведение кода к читаемому виду с настраиваемым размером отступа
- **Копирование в буфер обмена** - в один клик
- **Статистика** - количество символов и строк в редакторе
- **Тёмная тема** - минималистичный интерфейс с нумерацией строк
- **Горячие клавиши** - `Ctrl + Enter` запускает проверку
- **Ссылка на W3C Validator** - для углублённой проверки

## Поддерживаемые языки
| Язык | Что проверяется | Форматирование |
|------|-----------------|----------------|
| HTML / HTM | Валидность разметки через `DOMParser` | ✔️ |
| CSS | Синтаксис через `CSSStyleSheet.replaceSync()` | ✔️ |
| JavaScript | Полный разбор через **Acorn** (ES latest, модули) | ✔️ |
| JSON | `JSON.parse()` + точное определение позиции ошибки | ✔️ |
| XML / SVG | Разбор как HTML/XML | ✔️ |
| Python | Отступы, скобки, строки (включая тройные кавычки) | - |
| Go | Наличие package, скобки, строки (включая backtick) | - |
| Rust | Баланс скобок и строк | - |
| C++ | Баланс скобок `()`, `[]`, `{}` с учётом строк, символов и комментариев | - |
| BAT | Баланс кавычек и круглых скобок | - |
| Авто | Последовательная проверка всеми валидаторами | - |

## Технологии
- **Vanilla JavaScript** - без фреймворков
- CodeMirror 5 - редактор кода с подсветкой синтаксиса и нумерацией строк
- **Acorn** - парсер JavaScript
- **js-beautify** - форматирование JS, CSS и HTML
- **DOMParser / CSSStyleSheet / JSON** - встроенные браузерные API для валидации

## Как это работает
1. Вставьте код в редактор.
2. `detectLanguage()` анализирует содержимое регулярными выражениями и эвристиками, чтобы определить язык.
3. Вызывается соответствующий валидатор:
   - для JS - `acorn.parse()`;
   - для CSS - `CSSStyleSheet.replaceSync()`;
   - для HTML - `DOMParser` + поиск `parsererror`;
   - для JSON - `JSON.parse()`;
   - для Python - проверка отступов + общий сканер строк и скобок;
   - для Go - проверка package + общий сканер строк и скобок;
   - для Rust и C++ - общий сканер скобок, строк и комментариев;
   - для BAT и C++ - собственные сканеры баланса скобок и кавычек.
4. Ошибки отображаются в панели результатов, а строки с ошибками подсвечиваются в нумерации.
5. Кнопка «Форматировать» применяет `js-beautify` (или `JSON.stringify`) к коду, если ошибок не найдено.
